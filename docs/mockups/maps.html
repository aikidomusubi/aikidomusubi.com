Three map styles for the location heroes

Sanzo Wada dictionary entries where a colour is chosen, and LESS-style darken/lighten of those entries where a ramp is needed — the rule styles/base.less already follows. Each is shown on its own and again behind the real .lo-hero scrim with the real furniture, because the second is the only view that matters.

The synthetic city is not Badalona. Drawing a fake one would invite you to judge the geography instead of the palette, and the geography is Google’s. Paste the JSON into snazzymaps.com/editor to see each style on the real place.
