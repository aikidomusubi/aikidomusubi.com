Render the location heroes from OpenStreetMap

MapLibre over OpenFreeMap vector tiles — no key, no quota, and renderable at any size. The three palettes are the same ones as the Snazzy Maps styles; they are imported from the file that owns them.

ODbL. The data is OpenStreetMap’s and wants one line of credit. Keep “© OpenStreetMap contributors” on the page that shows the image — the hero prints it bottom-right. It is not optional and it is not onerous.
