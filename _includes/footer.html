The closed panel is translated off-screen, and it was meant to be `visibility: hidden` as well — but that flips through a transition with a delay, and the delayed step does not land, so it stays `visible`. An off-screen element that is still visible is still focusable: once Ura had been opened once, closing it left 168 tabbable elements inside a container marked `aria-hidden="true"`, which is both a lost keyboard user and an ARIA contradiction.
