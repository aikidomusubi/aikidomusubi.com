{%- comment -%} Consent control for the cookie policy pages. This is deliberately NOT a cookie-settings page. There is exactly one non-essential category (Google Analytics via GTM), so a panel of toggles would be theatre: it would imply choices that do not exist. What a visitor actually needs is to see what they chose and change it, which is what this does. All the consent logic lives in _includes/cookie-banner.html and is reached through window.amCookies. Nothing here writes a cookie by itself, so the banner and this control can never disagree about what "accepted" means.
