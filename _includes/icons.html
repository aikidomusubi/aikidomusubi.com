{%- comment -%} Favicons and app icons, all generated by tools/make-favicons.py from tools/favicon-source/logo-15.png: the knot in White on Black. The .ico carries sizes="32x32" on purpose. A browser that understands the SVG then prefers it, and one that does not still gets the tuned 16/32/48 bitmaps. /favicon.ico is a copy for clients that ask for it blindly; it is not the one linked, because it held the old picture and is cached as such. The PNGs are for Safari, which does not reliably use an SVG favicon, and for search engines, which want 48px multiples. The names carry a generation number (musubi2-*, GEN in the script): a favicon is cached hard, and a changed picture under an old name would stay in browsers for months. {%- endcomment %}
