{%- comment -%} Favicons and app icons, all generated by tools/make-favicons.py from tools/favicon-source/logo-15.png: the knot in Yellow on Black. /favicon.ico carries sizes="32x32" on purpose. A browser that understands the SVG then prefers it, and one that does not (and anything that asks for /favicon.ico without reading this) still gets the tuned 16/32/48 bitmaps. The PNGs are for Safari, which does not reliably use an SVG favicon, and for search engines, which want 48px multiples. The names are all new (musubi-*): a favicon is cached hard, and the old picture under an old name would have stayed in browsers for months. {%- endcomment %}
