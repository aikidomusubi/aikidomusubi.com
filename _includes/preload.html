{% comment %} The preconnects to fonts.googleapis.com and fonts.gstatic.com are gone with the fonts themselves — everything is served from this origin now, so there is no third party to warm up a connection to. {% endcomment %} {% if page.i18n-ref == 'index-8oGCaMDs' %} {% comment %} Hero is a CSS background-image swapped at 1200/1920/2560px (see default.less). Each preload carries the matching media query so the browser fetches exactly the one variant the stylesheet will actually paint — never a wasted download. `fetchpriority="high"` because this IS the largest contentful paint: it is a CSS background on `.fixedHead`, so the browser cannot know from the markup that it matters, and a preload without it queues at the same priority as everything else. Lighthouse's LCP-request-discovery audit asks for it by name. {% endcomment %} {% endif %} {% comment %} Only the two roman latin faces are preloaded. They are what body copy and headings paint with on every page, and the browser cannot discover them until it has parsed the stylesheet, so preloading buys a full round trip. The italic and latin-ext faces are deliberately left out: preloading a face the page never uses costs a download and, being crossorigin, one the browser cannot reuse. font-display: swap covers them. crossorigin is required even for same-origin fonts — without it the preload is fetched in a different mode from the CSS request and the file is downloaded twice. {% endcomment %}
